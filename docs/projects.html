How it works, in full: Group data platform

What it is

Designed and built from scratch. Data from a cloud data warehouse (Snowflake), on-premises sources (through a data gateway), SharePoint, Dataverse and file stores lands in a layered lakehouse (raw, cleaned, business-ready), organised by subject area: finance, clients, operations and more. One orchestration pipeline runs the whole chain through the day with explicit failure rules (what may carry on, what must stop) and an alert at each stage. On top sit governed semantic models with row-level security, a SQL database for apps, and natural-language data agents.

How it works, in full: Automation suite

What it is

A set of solutions that take manual processes off people’s desks: a finance approval workflow (a form, a tracked list, an approval chain and a hand-off to finance), collecting data from external partners (requests out, answers back, checked and archived), data-sync solutions that keep a working SharePoint list in step with governed data (a dataflow prepares the data; one flow creates new items, one updates changed ones, one archives what has gone, so people work in a familiar list while the data stays governed), and read-only health monitors that check every flow and data pipeline every day and send a digest plus failure alerts. Flows are defined in code by a build script and compared with what is live before any change, with read-only allow-lists for the monitors.

Money Ledger

A local finance app: drop in bank exports and get one ledger.

  • Python
  • FastAPI
  • SQLite
  • Vanilla JS

What it does

Drop in bank CSV exports; it identifies the bank, de-duplicates everything into one ledger, finds transfers, subscriptions and money leaks, and explains them in plain English.

Plain code does the deterministic work; specialist AI agents step in only at judgement points, with validated outputs. Every guess is logged for review and user rules always win. There is an offline test suite with a fake AI engine.

What I learnedKeep AI to the judgement calls; plain code is cheaper, faster and testable for everything else.
